# themes/admin/

Stubs iMSCP pour les pages **admin**. Ces fichiers sont **obligatoires** — iMSCP les cherche avant de charger une page.

## Contenu requis

Un fichier `.tpl` par page, avec uniquement :

```
<!-- DataBuilder managed page -->
```

## Pour chaque nouvelle page admin

Créer `themes/admin/nom_de_la_page.tpl` avec le contenu ci-dessus.

Le vrai rendu est géré par DataBuilder — ce fichier est juste un marqueur pour iMSCP.

> **Ne jamais mettre de vraie logique ici.**
