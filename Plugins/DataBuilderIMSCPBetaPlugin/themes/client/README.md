# themes/client/

Stubs iMSCP pour les pages **client**. Ces fichiers sont **obligatoires** — iMSCP les cherche avant de charger une page.

## Contenu requis

Un fichier `.tpl` par page, avec uniquement :

```
<!-- DataBuilder managed page -->
```

## Pour chaque nouvelle page client

Créer `themes/client/nom_de_la_page.tpl` avec le contenu ci-dessus.

> **Ne jamais mettre de vraie logique ici.**
